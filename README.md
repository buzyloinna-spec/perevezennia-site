# РУШАЙ — пасажирські перевезення

Односторінковий сайт (лендинг) для пасажирських перевезень з Кропивницького по всій Україні.

## Структура

```
index.html     — сторінка (HTML, CSS і JavaScript в одному файлі)
img/           — фото, превʼю для соцмереж, іконка вкладки
robots.txt     — дозвіл пошуковикам індексувати сайт
vercel.json    — налаштування для Vercel (кешування картинок)
```

Збирати нічого не потрібно: це статичний сайт без залежностей.

## Як переглянути локально

Відкрийте `index.html` у браузері (подвійний клік).

## Публікація

Підійде будь-який статичний хостинг:

- **GitHub Pages:** Settings → Pages → Source: «Deploy from a branch», гілка `main`, папка `/ (root)`.
- **Cloudflare Pages / Netlify:** підключіть репозиторій, команду збірки залиште порожньою, папка публікації — корінь.
- **Vercel:** імпортуйте репозиторій, налаштування за замовчуванням (`vercel.json` уже є).
